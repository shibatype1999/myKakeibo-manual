# CSV のインポート・エクスポート
<!-- position: 12 -->
<!-- description: 記録を CSV ファイルに書き出す方法と、CSV ファイルから記録を取り込む方法、CSV の形式を説明します。 -->

「設定」→「インポート・エクスポート」で、記録を CSV ファイルに書き出したり、CSV ファイルから取り込んだりできます。ほかの家計簿アプリからの乗り換えや、パソコンの表計算ソフトでの集計に使えます。

> カード会社・銀行からダウンロードした明細（Excel・CSV）を取り込むときは、「記録」タブの読み取りボタン →「D 表のファイル」が便利です。→ [レシート・明細を読み取る](scan)

## エクスポート（CSV）

1. **期間**を「すべて」「今年」「今月」「先月」から選びます。
2. 「CSVを書き出す」をタップします。
3. 共有メニューが開くので、保存先（「ファイル」に保存、メール、AirDrop など）を選びます。

書き出したファイルは、「ファイル」アプリの「このiPhone内」→「myKakeibo」→「exports」にも残ります。
書き出されるのは確定した記録だけです（予定の記録は含まれません）。ファイルは UTF-8（BOM 付き）なので、Excel で開いても文字化けしません。

## インポート（CSV）

1. 「ファイルを選ぶ」をタップし、CSV ファイルを選びます。
2. 取り込む前に、次の内容が表示されます。この時点ではまだデータは変わりません。
   - 追加する明細の件数
   - 重複のためスキップする件数（日時・種別・カテゴリ・金額が同じ記録がすでにあるもの）
   - 新しく作るカテゴリ・サブカテゴリ・口座
   - 読めなかった行と、その理由
3. 内容を確認し、「◯件をインポート」をタップします。

> **ヒント**
> - 「サンプルデータを読み込む」をタップすると、サンプルの CSV で取り込みの流れを試せます（「◯件をインポート」を押すまでは取り込まれません）。
> - Excel などで保存した Shift_JIS の CSV も読み込めます。
> - CSV にあるカテゴリ・サブカテゴリ・口座がアプリにない場合は、新しく作られます。新しく作られる口座の種類は「現金」です。必要に応じて「設定」→「口座」で変更してください。

## CSV の形式

1行目に見出し、2行目から記録を1件ずつ書きます。見出しの名前で列を判断するので、列の順番が違っていても読み込めます（英語の見出しでも読み込めます）。

| 列 | 内容 | 例 |
| --- | --- | --- |
| 日時 | 「2026/10/25 14:30」「2026-10-25」など。時刻がなければ 0:00 | 2026/10/01 12:10 |
| 種別 | 収入・支出・振替のどれか | 支出 |
| カテゴリ | 収入・支出では必須。振替では空 | 食費 |
| サブカテゴリ | 空でもかまいません | 食料品 |
| 金額 | 「3280」「3,280」「¥3,280」などで書けます | 5540 |
| メモ | 空でもかまいません | |
| 店舗名 | 空でもかまいません | コープ |
| 口座 | 支払い元・入金先。振替では出金元 | 財布 |
| 振替先 | 振替の入金先。振替では必須 | |

```
日時,種別,カテゴリ,サブカテゴリ,金額,メモ,店舗名,口座,振替先
2024/10/01 00:05,支出,デジタル・サブスク,動画配信,1490,Netflix,,クレジットカード,
2024/10/02 12:10,振替,,,30000,ATM,,銀行口座,財布
2024/10/02 17:45,支出,食費,食料品,5540,,コープ,財布,
```
