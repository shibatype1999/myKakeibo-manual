# Bulk Input Pages and Automatic Entries
<!-- position: 4 -->
<!-- description: How to use bulk input pages to enter monthly items such as rent, utilities and savings together, and how to record them automatically every month. -->

A **bulk input page** groups the items you enter every month, such as salary, rent, utilities and savings. Enter the amounts and tap one button to record them all. You can also have them recorded automatically on a set day.

Three pages are ready from the start: **Housing & Utilities**, **Phone & Subscriptions**, and **Loans & Insurance**.

## Opening the list of bulk input pages

Open it in either of these ways:

- The bulk input button (checklist icon) at the top right of the **Record** tab
- **Settings** → **Bulk Input Pages**

Tap a page to enter amounts. Tap the pencil at the top right to enter edit mode, where you can tap a page to edit its items, drag ≡ to reorder, and tap ⊖ to delete.

## Creating a page

1. In the list of bulk input pages, tap **+** at the bottom right.
2. Enter a page name (e.g. Monthly fixed costs) and tap **Save**.
3. The item editing screen opens. Add items with **+** at the bottom right.

Rename a page with the button at the top right of the item editing screen. Deleting a page keeps your recorded data.

## Adding and editing items

On the **Add item** screen, set the following:

| Setting | Description |
| --- | --- |
| Income / Expense / Transfer | The type of item. |
| Category | For income and expenses. (If you choose a subcategory, it is used to check whether the item is already entered for the month.) |
| Name, Withdraw from, Deposit to | For transfers. If the name is blank, it is shown as "From → To". |
| Default amount | The amount filled in on the input screen. It can be left blank. If the subcategory has a fixed monthly amount, that amount is used when this is blank. |
| Memo | A memo added to the record. |
| Register automatically every month | When on, this item is included in automatic entries (a default amount is required). |

Tap an item to edit it. Use the pencil at the top right to reorder or delete items.

## Entering amounts together

Tap a bulk input page, or choose **Bulk** on any tab of the **Record** screen and select a page, to show the input fields.

![Bulk input](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/en/bulk-input.png)

1. Check the **date & time** at the top. Tap it to change it. Below it, you see how many items are already entered for the month.
2. Choose the account in **Paid from / deposit to** (not shown on pages with only transfers).
3. Enter the amount for each item. Uncheck items you don't want to save. For transfer items, tap the from/to accounts to change them just this once.
4. Tap **Save checked items**.

> **Tips**
> - Items already entered this month are marked **Entered** and unchecked from the start to avoid entering them twice.
> - If you check an entered item and save, you are asked to confirm.
> - With **Bulk** on the Record tab, only pages that have items of that tab's type (income, expense or transfer) are shown.

## Registering automatically every month

Items with the same amount every month, like rent or savings, can be recorded automatically on a set day.

1. On the item editing screen, open an item, enter a default amount, and turn on **Register automatically every month**. The item is marked **Auto**.
2. At the top of the item editing screen, turn on the page's **Register automatically every month**.
3. Set the following:

| Setting | Description |
| --- | --- |
| Day | Day 1–28 of every month, or **End of month** |
| On weekends | **Keep the date**, **Previous Friday** or **Next Monday** |
| Time | The time to record |
| Paid from / deposit to | The account used for the records (Bank Account if not set) |

Records added automatically are marked **Auto** in the list.

> **Note**
> - On iPhone, records cannot be added while the app is closed. When you **open the app (or return to it from another app)**, any entries whose date and time have passed are recorded, and a message tells you how many were added.
> - If you haven't opened the app for a while, up to 12 months are recorded retroactively.
> - Entries start from the month you turned automatic registration on. Earlier months are not recorded.
> - Items already entered that month are not recorded automatically.

## How this differs from "Fixed monthly" subcategories

When **Fixed monthly** is on for a subcategory, a **Scheduled** record without a confirmed amount is created at the start of each month (shown in yellow in the list). Saving the same subcategory from a bulk input page confirms that scheduled record instead of creating a new one. See [Categories and subcategories](categories) for details.
