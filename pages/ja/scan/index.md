# レシート・明細を読み取る
<!-- position: 3 -->
<!-- description: レシート、通帳・入出金明細、カード・決済の明細、表のファイルを読み取って記録する方法を説明します。 -->

「記録」タブ右上の読み取りボタン（書類のアイコン）から、レシートや明細を読み取ってまとめて記録できます。

> **ご注意**
> 画像の文字の読み取りは推測です。お店や明細の書式によっては、日付・金額・内容が正しく読み取れないことがよくあります。登録前の確認画面で、必要に応じて手で直してください。

## 1. 何を読み取るかを選ぶ

「何を読み取りますか」と表示されたら、図を見て、いちばん近い形を選びます。前回選んだものには「前回」と表示されます。

![読み取る種類の選択](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/scan-kind.png)

| 種類 | 読み取る内容 |
| --- | --- |
| A レシート | 店名・商品と値段・合計 |
| B 通帳・入出金明細 | 日付・内容・出金/入金・残高 |
| C カード・決済の明細 | 店名と金額・日付（カード・PayPay・Suica など） |
| D 表のファイル | CSV・Excel（列に日付・内容・金額） |

## 2. 読み取り方を選ぶ

| 読み取り方 | 内容 |
| --- | --- |
| カメラでスキャン | カメラで撮影します。複数ページをまとめて撮ると、上から順につなげて読み取ります。撮影した画像は保存されません。 |
| 写真から選ぶ | 写真アプリの画像（スクリーンショットなど）を読み取ります。 |
| ファイルから選ぶ | 「ファイル」アプリの画像（JPEG・PNG・HEIC）を読み取ります。 |
| テキストを貼り付ける | コピーした文字を貼り付けて読み取ります。写真アプリでレシートの文字を長押し →「すべてを選択」→「コピー」で取り込めます。 |

種類を選び直すときは、右上の「変更」をタップします。
「D 表のファイル」を選んだ場合は、ファイルを選ぶとそのまま確認画面が開きます（Excel（.xlsx）・CSV に対応）。

## 3. 読み取り結果を確認して登録する

「読み取り結果の確認」画面で内容を確認・修正し、下の「◯件を登録」をタップします。
上部の切り替えで、登録のしかたを選べます。

| 切り替え | 登録のしかた |
| --- | --- |
| 商品ごと | レシートの商品1つずつを、別々の記録として登録します。 |
| 合計1件 | レシートの合計を1件の記録として登録します。 |
| 入出金明細 | 通帳・明細の1行ずつを記録として登録します。 |

![読み取り結果の確認](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/scan-confirm.png)

### レシート（商品ごと・合計1件）

- **日時**・**店舗名**・**カテゴリ**・**支払い元**を確認します。商品ごとの場合、カテゴリは「カテゴリ（まとめて変更）」で全部の商品をまとめて変えられます。
- 商品ごとの場合は、チェックした商品だけが登録されます。商品名・金額の修正、「行を追加」、行の削除もできます。
- 「チェックした合計」と「レシートの合計」に差があるときは、「◯ の差（消費税など）」と表示されます。
- 同じ店舗名で前に登録したことがあると、そのときのカテゴリが最初から選ばれます。

### 通帳・明細（入出金明細）

- 上部の**口座**で、その通帳・明細の口座を選びます。
- 各行の日付・内容・金額と、支出／収入・カテゴリを確認します。種類のところを押すと「支出」「収入」「振替（この口座へ）」「振替（この口座から）」を切り替えられます。
- 「チャージ」の行は、振替として読み取ります。振替の行では、相手の口座を選んでください。
- すでに同じ日・同じ金額の記録がある行には「記録済み」と表示され、チェックが外れます（二重登録の防止）。
- 日付が読めなかった行には「日付?」と表示されます。押して日付を選んでください。
- カテゴリを選んでいない行があると、登録の前にお知らせが出ます。

### 読み取った全文を見る

右上の全文ボタンを押すと、読み取ったすべての行が表示されます。日付・店舗名・商品・合計などとして読み取った行には札が付いています。札のない行は ⊕ で商品（明細）に追加できます。読み取りもれがあるときに使ってください。

## AI で読み取りを整理する（対応する iPhone のみ）

Apple Intelligence に対応した iPhone では、読み取った文字から、端末の中の AI で日付・品名・金額を整理します。処理はすべて端末の中で行われます。

- 整理が終わると「AIで整理しました」と表示されます。「元に戻す」で AI を使わない読み取り結果に、「AIの結果に戻す」で AI の結果に切り替えられます。
- AI で整理できなかったときは、理由とともに、いつもの読み取り結果が表示されます。
- AI を使わない場合は、「設定」→「AIで読み取りを整理する」をオフにします。
- 小数のある通貨（ドルなど）を使っているときや、表のファイルの取り込みでは AI は使われません。
