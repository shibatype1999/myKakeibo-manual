# myKakeibo マニュアル

家計簿アプリ myKakeibo（開発リポジトリ: `mykakeibo`）の**利用者向け操作マニュアル**です。
Bludit の **Remote Content** プラグインで取り込み、サイトとして公開することを想定した構成になっています（`assett-manual` と同じ構成です）。

- 対象のアプリのバージョン: **1.0.0 (18)**
- 対応OS: **iOS**
- 対応言語: **日本語** / **英語**

## Bludit で読み込まれるしくみ

Remote Content プラグインは、指定した zip ファイルをダウンロードし、次のルールでページを作成します。

- zip の中の `pages/<親>/index.md` が**親ページ**、`pages/<親>/<子>/index.md` が**子ページ**になります（2階層まで）。
- **フォルダ名がそのままURL（スラッグ）**になります。例: `pages/ja/summary/index.md` → `https://サイト/ja/summary`
- ファイルの**1行目の `# 見出し`がページタイトル**になります。
- 2行目から続く `<!-- 項目: 値 -->` の行は、ページの設定として読み込まれます（`position`: 並び順、`description`: 説明文）。

> **注意**
> - `<!-- … -->` の行は**タイトルの直後に、空行を入れずに**書いてください。
> - 取り込みを実行すると、**Bludit に登録されている既存のページとアップロード済みの画像はすべて削除**され、このリポジトリの内容に置き換わります。

## Bludit の設定手順

1. このリポジトリを **Public（公開）** にします（Bludit は認証なしで zip と画像をダウンロードするため）。
2. 変更を `main` ブランチに反映します。
3. Bludit の管理画面で **Remote Content** プラグインを有効にし、**Source** に次を設定します。
   `https://github.com/shibatype1999/myKakeibo-manual/archive/refs/heads/main.zip`
4. 「Try webhook」で取り込みます。GitHub の Webhook に Bludit の Webhook のURLを登録すると、`main` へのプッシュ時に自動で更新されます。

## 執筆ルール

- **フォルダ名（スラッグ）は全言語で共通**にします。スラッグは半角英小文字とハイフンで付けます。
- アプリの画面上の文言は「」（英語版は **太字**）で囲み、アプリ内の表記（`mykakeibo` リポジトリの `lib/l10n/app_ja.arb`・`app_en.arb`）と一致させます。
- **ページ間のリンク**
  - 子ページから同じ言語の別の子ページへ: スラッグだけを書きます。例: `[予算](budget)`
  - 親ページ（`pages/<言語>/index.md`）から子ページへ: `言語/スラッグ` と書きます。例: `[予算](ja/budget)`
  - 見出しへのリンク（`#…`）は Bludit では使えないため、書かないでください。
- **画像**は GitHub 上のファイルを絶対URLで参照します。
  ```markdown
  ![記録画面](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/record.png)
  ```
  撮影が必要な画像の一覧は [images/README.md](images/README.md) を参照してください。

## 用語

| 用語 | 意味 |
| --- | --- |
| 収入・支出 | お金が入ってきた・出ていった記録 |
| 振替 | 自分の口座どうしのお金の移動（収支に入らない） |
| カテゴリ／サブカテゴリ | 収入・支出の分類と、その内訳 |
| 口座 | お金の置き場所（現金・銀行・カード・電子マネー・投資） |
| 一括入力ページ | 毎月入力する項目をまとめたページ。自動登録もできる |
| 予定 | 「毎月固定」のサブカテゴリから毎月はじめに作られる、未確定の記録 |
