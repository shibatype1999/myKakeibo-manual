# 一覧で確認・修正する
<!-- position: 5 -->
<!-- description: 「一覧」タブで、月ごとの記録をカレンダーと一覧で確認し、修正・削除する方法を説明します。 -->

「一覧」タブでは、1か月分の記録を、カレンダーと日付ごとの一覧で確認できます。

![一覧画面](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/list.png)

## 表示を切り替える

- **収入・支出・振替** … 上部のタブをタップして切り替えます。開いたときは「支出」が表示されます。
- **月** … 年月の左右の矢印をタップするか、画面を左右にスワイプして前後の月に移ります。
- **カレンダーの開け閉め** … カレンダーの下のつまみ（または月の合計の帯）をタップして開け閉めします。開け閉めの状態は次回も引き継がれます。

月の合計（収入合計・支出合計・振替の合計）は、カレンダーの上に表示されます。

## カレンダー

カレンダーの各日には、その日の合計金額が表示されます。

- 日付をタップすると、**その日の記録だけ**が一覧に表示されます。上に「◯ の記録」と表示されます。
- もう一度同じ日をタップするか、「◯ の記録」の × をタップすると、月全体の表示に戻ります。

## 一覧の見かた

記録は新しい日付から順に、日ごとにまとめて表示されます。日付の見出しの右にはその日の合計が表示されます（日曜日は赤、土曜日は青）。

各行には、時刻・カテゴリのアイコン・「カテゴリ / サブカテゴリ」・金額が表示され、下にメモ・店舗名・口座が表示されます。

| 表示 | 意味 |
| --- | --- |
| 黄色の行・「予定」・砂時計のアイコン | 毎月固定のサブカテゴリから作られた、まだ確定していない予定の記録です。集計には入りません。 |
| 自動登録 | 一括入力ページの自動登録で登録された記録です。 |
| 出金元 → 入金先 | 振替の記録です。 |

## 記録を修正・削除する

1. 一覧で記録をタップすると、「記録の編集」が開きます。
2. 金額・カテゴリ・口座・日時・メモ・店舗名を直し、「保存」をタップします。
3. 削除する場合は「削除」をタップし、確認で削除します。削除した記録は元に戻せません。

### 予定の記録を確定する

「予定」の記録をタップすると、「予定の記録です。確定すると集計に入ります」と表示されます。金額を入れて「確定」をタップすると、通常の記録になり集計に入ります。
