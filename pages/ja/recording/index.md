# 収入・支出・振替を記録する
<!-- position: 2 -->
<!-- description: 「記録」タブで、収入・支出・振替を1件ずつ入力する方法を説明します。 -->

「記録」タブでは、上部の「収入」「支出」「振替」を切り替えて入力します。開いたときは「支出」が選ばれています。

![記録画面](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/record.png)

各タブの上には「個別」と「一括」の切り替えがあります。

- **個別** … 1件ずつ入力します（このページで説明します）。
- **一括** … 一括入力ページを選んで、決まった項目をまとめて入力します。→ [一括入力ページと自動登録](bulk-input)

どちらを選んだかはタブごとに覚えられ、次に開いたときも同じ表示になります。切り替えても入力途中の内容は消えません。

右上の2つのボタンは次のとおりです。

| ボタン | できること |
| --- | --- |
| 読み取り（書類のアイコン） | レシート・通帳・明細を読み取ります。→ [レシート・明細を読み取る](scan) |
| 一括入力（チェックリストのアイコン） | 一括入力ページの一覧を開きます。 |

## 支出・収入を記録する

1. 「支出」（または「収入」）タブで「個別」を選びます。
2. **金額**を入力します。
3. **カテゴリ**の欄をタップし、カテゴリとサブカテゴリを選びます（下の「カテゴリの選びかた」を参照）。
4. **支払い元**（収入の場合は**入金先**）の口座を選びます。
5. 必要に応じて**日時**・**メモ**を入力します。支出では**店舗名**も入力できます。
6. 「保存」をタップします。

保存すると「保存しました」と表示され、金額・サブカテゴリ・メモ・店舗名が空に戻ります。カテゴリ・口座・日時はそのまま残るので、続けて入力できます。

> **ヒント**
> - 口座は、前回その種類の記録で選んだ口座が最初から選ばれます。はじめは、支出は「財布」、収入は「銀行口座」です。
> - 入力欄の外をタップすると、キーボードが閉じます。

### カテゴリの選びかた

カテゴリの欄をタップすると、カテゴリのアイコンが並んだシートが開きます。

1. カテゴリのアイコンをタップすると、その下に「◯◯ の内訳」としてサブカテゴリが表示されます。
2. サブカテゴリを選びます。サブカテゴリを付けない場合は「◯◯のみ」を選びます。

![カテゴリの選択](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/category-picker.png)

カテゴリ・サブカテゴリは「設定」で追加・並び替えできます。→ [カテゴリ・サブカテゴリ](categories)

### 口座の選びかた

口座の欄をタップすると、口座のアイコンが「お金」「投資」に分かれて並んだシートが開きます。使う口座をタップします。
収入・支出では「お金」の口座（現金・銀行・カード・電子マネー）だけが表示されます。投資口座へのお金の移動は「振替」で記録します。

## 振替を記録する

振替は、ATM での引き出し、電子マネーへのチャージ、NISA・iDeCo への積立、カードの引き落としなど、**自分の口座どうしのお金の移動**です。収入・支出の合計には入りません。

1. 「振替」タブで「個別」を選びます。
2. **金額**を入力します。
3. **出金元**と**入金先**の口座を選びます。
4. 必要に応じて**日時**・**メモ**を入力し、「保存」をタップします。

「よく使う振替」には、最近使った口座の組み合わせと、銀行口座から投資口座・財布・カードへの組み合わせが表示されます。タップすると、出金元と入金先がまとめて入ります。

> **ご注意**
> 出金元と入金先には、別の口座を選んでください。同じ口座を選ぶと保存できません。

## 入力した記録を直すには

「一覧」タブで記録をタップすると、修正・削除できます。→ [一覧で確認・修正する](list)
