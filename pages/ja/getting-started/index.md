## 画面構成

画面下部のタブで、4つの画面を切り替えます。アプリを起動すると「記録」が表示されます。

![画面下部のタブ](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/tab-bar.png)

| タブ | できること |
| --- | --- |
| 記録 | 収入・支出・振替を入力します。右上のボタンから、レシートなどの読み取りと一括入力も行えます。 |
| 一覧 | 月ごとの記録をカレンダーと日付順の一覧で確認し、修正・削除します。 |
| 集計 | 収支・収入・支出を、月ごと・年ごとのグラフで確認します。予算の状況もここに表示されます。 |
| 設定 | カテゴリ・口座・予算・バックアップ・テーマ・プレミアムなどを設定します。 |

> 無料でお使いの場合、下部のタブの上に広告が表示されます。[プレミアム](premium)にすると表示されなくなります。

## 用語

| 用語 | 意味 | 例 |
| --- | --- | --- |
| 収入・支出 | お金が入ってきた記録・出ていった記録です。 | 給料、食料品の買い物 |
| 振替 | 自分の口座どうしのお金の移動です。収入・支出には入りません。 | ATM での引き出し、電子マネーへのチャージ、NISA への積立 |
| カテゴリ | 収入・支出の大きな分類です。 | 食費、光熱費、給与 |
| サブカテゴリ | カテゴリの内訳です。 | 食費 › 外食、光熱費 › 電気代 |
| 口座 | お金の置き場所です。記録ごとに「支払い元」「入金先」として選びます。 | 財布、銀行口座、クレジットカード、つみたてNISA |
| 一括入力ページ | 毎月入力する項目をまとめたページです。まとめて入力・自動登録できます。 | 住まい・光熱費、通信・サブスク |

## はじめから用意されているもの

はじめてアプリを起動すると、次のものがあらかじめ用意されています。使わないものは削除や名前の変更ができます。

- **カテゴリ** … 支出は「食費」「日用品」「住居費」「光熱費」「通信費」など20種類、収入は「給与」「副業」「臨時収入」「投資」「その他収入」。それぞれにサブカテゴリも入っています。
- **口座** … 「財布」「銀行口座」「へそくり」「定期預金」「財形貯蓄」「クレジットカード」「つみたてNISA」「iDeCo」「NISA成長投資枠」「投資信託」「株式」
- **一括入力ページ** … 「住まい・光熱費」「通信・サブスク」「ローン・保険・社会保険」

## はじめて使うときの流れ

1. **口座を整える**
   「設定」→「口座」で、お使いの口座を追加し、使い始める時点の残高を入れます。
   → [口座と振替](accounts)
2. **毎日の支出を記録する**
   「記録」タブで金額とカテゴリを選んで「保存」します。レシートは右上のボタンから読み取れます。
   → [収入・支出・振替を記録する](recording) / [レシート・明細を読み取る](scan)
3. **毎月の決まった出費を整える（任意）**
   家賃・光熱費・積立などを一括入力ページにまとめると、毎月数回のタップで入力でき、自動登録もできます。
   → [一括入力ページと自動登録](bulk-input)
4. **予算を決める（任意）**
   「設定」→「予算」で月の予算を入れると、集計で残りの金額を確認できます。
   → [予算](budget)
5. **一覧と集計で振り返る**
   → [一覧で確認・修正する](list) / [集計とグラフ](summary)

> **ヒント**
> 記録はすべて端末の中に保存されます。機種変更や故障に備えて、ときどきバックアップを取ってください。
> → [バックアップ・リストア・データの初期化](backup)
