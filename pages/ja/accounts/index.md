# 口座と振替
<!-- position: 8 -->
<!-- description: 財布・銀行口座・クレジットカード・電子マネー・投資口座の管理と、残高の考えかた、振替について説明します。 -->

**口座**は、お金の置き場所です。記録ごとに「支払い元」「入金先」として口座を選ぶと、口座ごとの残高がわかります。

## 口座の一覧と残高

「設定」→「口座」を開くと、口座ごとの残高と、いちばん上に**資産の合計**が表示されます。口座は「お金」と「投資」に分かれて表示されます。

![口座の一覧](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/accounts.png)

残高は次のように計算されます（確定した記録のみ）。

> 最初の残高 ＋ 収入 − 支出 − 振替で出たお金 ＋ 振替で入ったお金

| 種類 | 残高の見かた |
| --- | --- |
| 現金・銀行・電子マネー | 今ある金額です。 |
| カード | 使った分がマイナスで表示されます。カードの引き落としを「銀行口座 → クレジットカード」の振替で記録すると、0 に戻ります。 |
| 投資 | **積み立てた元本**です（値上がり・値下がりは反映されません）。 |

## 口座を追加・編集する

1. 「口座」の画面で右下の「+」をタップします（編集するときは口座をタップします）。
2. 次の内容を設定し、「保存」をタップします。

| 設定 | 内容 |
| --- | --- |
| 口座名 | 例: A銀行、楽天カード |
| 種類 | 現金・銀行・カード・電子マネー・投資 |
| 最初の残高 | 使い始めた時点の残高です。カードは未払いの利用額をマイナスで、投資はすでに積み立てている元本を入力します。 |
| アイコン・色 | 一覧や選択画面に表示されるアイコンと色です。 |

### 口座を削除する

口座の編集画面の右上のごみ箱をタップします。口座を削除しても記録は残り、記録の口座の指定だけが外れます。

## 振替とは

**振替**は、自分の口座どうしのお金の移動です。収入・支出には入らず、口座の残高だけが変わります。

| 例 | 出金元 → 入金先 |
| --- | --- |
| ATM でお金を引き出した | 銀行口座 → 財布 |
| 電子マネーにチャージした | 銀行口座（または財布） → 電子マネー |
| クレジットカードの引き落とし | 銀行口座 → クレジットカード |
| つみたてNISA・iDeCo に積み立てた | 銀行口座 → つみたてNISA など |
| クレジットカードで投資信託を積み立てた | クレジットカード → 投資信託 など |

振替は「記録」タブの「振替」で入力します。→ [収入・支出・振替を記録する](recording)
投資口座への振替は、集計の「投資に回した額」に表示されます。→ [集計とグラフ](summary)

> **ヒント**
> クレジットカードで買い物をしたときは、支払い元を「クレジットカード」にして支出を記録します。引き落とし日に「銀行口座 → クレジットカード」の振替を記録すると、支出を二重に数えずに、銀行口座とカードの残高を正しく保てます。
