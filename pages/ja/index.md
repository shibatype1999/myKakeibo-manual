# myKakeibo ご利用ガイド
<!-- position: 1 -->
<!-- description: 家計簿アプリ myKakeibo の使いかたをまとめたご利用ガイドです。 -->

myKakeibo は、毎日の記録は手早く、毎月決まった出費はもっと手軽に入力できる家計簿アプリです。

![記録画面](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/record.png)

## このアプリでできること

- **撮って読み取る** … レシート、通帳・入出金明細、クレジットカードや決済アプリの利用明細を、カメラや写真から読み取って記録します。CSV や Excel の表からも取り込めます。
- **毎月の決まった出費をまとめて入力** … 家賃・光熱費・積立などを「一括入力ページ」にまとめ、数回のタップで入力できます。毎月決まった日に自動で登録することもできます。
- **カレンダーで一覧** … 日ごとの合計をカレンダーで確認し、記録を押せばその場で修正・削除できます。
- **集計とグラフ** … カテゴリ別の円グラフと割合、月ごと・年ごとの推移、累計グラフ、前年との比較を表示します。
- **予算** … 月の予算（全体・カテゴリ別）を決めて、残りの金額や予算内だった月の数を確認できます。
- **口座と振替** … 財布・銀行口座・クレジットカード・電子マネー・投資口座を管理し、口座どうしの移動（振替）は収支と分けて記録します。
- **自分好みの見た目** … 15種類のスキンとテーマカラー、ライト／ダークを選べます。
- **データを守る** … 端末内へのバックアップ、パスコードロック、プレミアムでは iCloud への自動バックアップが使えます。

家計簿のデータは、すべてお使いの端末の中に保存されます。画像の読み取りも端末の中で行います。アカウント登録は必要ありません。
