# スクリーンショットの撮影リスト

本文から参照している画像です。所定のファイル名で `images/ja/`（日本語表示）・`images/en/`（英語表示）に置き、`main` ブランチに反映すると表示されます。
対象のアプリのバージョン: **1.0.0 (18)**

| ファイル名 | 使うページ | 撮る画面 |
| --- | --- | --- |
| `record.png` | トップ、記録する | 「記録」タブ（支出・個別）。金額・カテゴリ・口座を入れた状態 |
| `tab-bar.png` | はじめに | 画面下部のタブ（記録・一覧・集計・設定）。広告の部分は切り取るか、プレミアムの状態で撮影 |
| `category-picker.png` | 記録する | カテゴリの選択シートで、カテゴリを1つ開いてサブカテゴリが見えている状態 |
| `scan-kind.png` | 読み取る | 「何を読み取りますか」（A〜D の図） |
| `scan-confirm.png` | 読み取る | 「読み取り結果の確認」（レシート・商品ごと）。個人情報が写らないサンプルのレシートで |
| `bulk-input.png` | 一括入力ページ | 一括入力の入力画面（「住まい・光熱費」など）。「入力済み」と「自動」が見える状態だとよい |
| `list.png` | 一覧 | 「一覧」タブ（支出）。カレンダーを開き、日付ごとの一覧が見える状態 |
| `summary.png` | 集計 | 「集計」タブ →「支出」→「月」。円グラフとカテゴリ別の横棒 |
| `budget.png` | 予算 | 「集計」タブ →「収支」→「月」。今月の予算とカテゴリ別の予算 |
| `accounts.png` | 口座と振替 | 「設定」→「口座」。資産の合計と「お金」「投資」 |
| `backup.png` | バックアップ | 「設定」→「バックアップ・リストア」。iCloud と端末内の両方が見える状態 |
| `theme.png` | 設定 | 「設定」→「テーマ」。スキンの一覧 |

## 撮影のときの注意

- 実際の口座名・金額・店名など、個人を特定できる情報が写らないようにしてください（サンプルデータの利用をおすすめします。「設定」→「インポート・エクスポート」→「サンプルデータを読み込む」）。
- 縦向き・同じ機種で撮影し、ステータスバーの時刻などはそろえると見やすくなります。
- 英語版は、端末の言語を英語にして撮影します。
