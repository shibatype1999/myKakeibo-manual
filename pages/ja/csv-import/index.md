# CSV で記録を取り込む（フォーマットの解説）
<!-- position: 13 -->
<!-- description: CSV ファイルから記録を取り込むときのおすすめのフォーマット、各列の書き方、エラーの直し方、ほかの家計簿アプリからの移行方法を説明します。 -->

ほかの家計簿アプリや表計算ソフトで付けていた記録を、CSV ファイルからまとめて取り込めます。
このページでは、取り込みに失敗しないための**おすすめのフォーマット**と、作り方のコツを説明します。操作の手順は [CSV のインポート・エクスポート](import-export) をご覧ください。

> **取り込む前にバックアップを**
> 取り込んだ記録を、まとめて取り消す機能はありません。取り込む前に「設定」→「バックアップ・リストア」→「今すぐバックアップ」でバックアップを取っておくと、うまくいかなかったときに元に戻せます。→ [バックアップ・リストア・データの初期化](backup)

## 2つの取り込み方の違い

CSV の取り込み方は2つあります。手元のファイルに合わせて選んでください。

| | 設定 →「インポート・エクスポート」 | 記録 → 読み取り →「D 表のファイル」 |
| --- | --- | --- |
| 向いているファイル | このページの形式に整えた CSV（ほかの家計簿アプリから移行するときなど） | 銀行・カード会社からダウンロードした明細そのまま |
| 対応形式 | CSV（.csv） | CSV・TSV・Excel（.xlsx） |
| カテゴリ・口座 | ファイルの列で指定（なければ自動で作成） | 確認画面で1行ずつ選ぶ |
| 振替 | 取り込める | 取り込める（確認画面で種類を切り替え） |
| 重複の扱い | 同じ記録があれば自動でスキップ | 同じ日・同じ金額の記録があれば「記録済み」でチェックが外れる |

明細のファイルを「D 表のファイル」で取り込むときのコツは、このページの最後にまとめています。

## おすすめのフォーマット

いちばん確実なのは、**アプリから書き出した CSV と同じ形**にすることです。「設定」→「インポート・エクスポート」→「CSVを書き出す」で書き出したファイルを、そのままひな形として使えます。

ひな形のファイルもダウンロードできます: [import_template_ja.csv](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/templates/import_template_ja.csv)

```
日時,種別,カテゴリ,サブカテゴリ,金額,メモ,店舗名,口座,振替先
2026/10/01 08:30,支出,食費,食料品,1280,,スーパーA,財布,
2026/10/01 12:10,支出,食費,外食,950,ランチ,,クレジットカード,
2026/10/05 00:00,収入,給与,給料,250000,,,銀行口座,
2026/10/05 09:00,振替,,,30000,ATM,,銀行口座,財布
2026/10/27 00:00,支出,住居費,家賃,85000,10月分,,銀行口座,
2026/10/27 00:00,振替,,,33000,積立,,銀行口座,つみたてNISA
```

### ポイント

1. **1行目に見出し**を入れます。見出しは `日時,種別,カテゴリ,サブカテゴリ,金額,メモ,店舗名,口座,振替先` の9つです。
2. 見出しがあれば、**列の順番は自由**で、使わない列（メモ・店舗名など）は省けます。英語の見出し（`Date,Type,Category,Subcategory,Amount,Memo,Store,Account,To account`）でも読み込めます。
3. 2行目から、**1行に1件**の記録を書きます。
4. ファイルは **CSV（カンマ区切り）・UTF-8** で保存します。

### 最小限の列

最低限必要なのは次の列です。

| 記録の種類 | 必要な列 |
| --- | --- |
| 収入・支出 | 日時・種別・カテゴリ・金額 |
| 振替 | 日時・種別・金額・口座・振替先 |

ただし、**口座**を入れておくと、口座ごとの残高が正しく計算されます。口座が空の記録は、どの口座の残高にも入りません。

## 各列の書き方

### 日時（必須）

| 書き方 | 読み込み |
| --- | --- |
| `2026/10/25 14:30` | ◯（おすすめ） |
| `2026-10-25 14:30:00`、`2026-10-25T14:30` | ◯（秒は無視されます） |
| `2026/10/25`、`2026/1/5` | ◯（時刻は 0:00 になります） |
| `10/25`（年がない） | ✕ |
| `2026年10月25日`、`令和8年10月25日` | ✕ |
| `25/10/2026`、`10/25/2026` | ✕ |

**年（4桁）・月・日の順**で、区切りは `/` か `-` にしてください。Excel で日付のセルの表示形式が「2026年10月25日」などになっていると、そのまま CSV に書き出されて読み込めません。表示形式を `yyyy/mm/dd hh:mm` などに変えてから保存してください。

### 種別（必須）

`収入`・`支出`・`振替` のどれかを書きます（英語の `Income`・`Expense`・`Transfer` も可）。「入金」「出金」などは読み込めないので、置き換えてください。

### 金額（必須）

| 書き方 | 読み込み |
| --- | --- |
| `3280`、`3,280`、`¥3,280`、`3,280円` | ◯ |
| 全角の数字（`３２８０`） | ◯ |
| `-3280`（マイナス）、`0` | ✕ |

- 金額は**いつもプラス**で書きます。お金の向きは「種別」で決まります。ほかのアプリで支出をマイナスで書き出している場合は、マイナスを外してください。
- 小数は、アプリで選んでいる通貨の桁数までです。日本円では小数点以下は四捨五入されます。

### カテゴリ・サブカテゴリ

- 収入・支出では**カテゴリが必須**です。振替では空にします（書いても使われません）。
- サブカテゴリは空でもかまいません。
- アプリにあるカテゴリと**名前が完全に一致**すると、そのカテゴリに入ります。一致しないと**新しいカテゴリが作られます**。「食費」と「食 費」、全角と半角の違いでも別のカテゴリになるので、アプリの「設定」→「カテゴリ」の名前に合わせておくのがおすすめです。
- 同じ名前でも、収入と支出は別のカテゴリとして扱います（例: 収入の「その他」と支出の「その他」）。
- 新しく作られたカテゴリのアイコン・色は、あとから「設定」→「カテゴリ」で変えられます。

### 口座・振替先

- **口座**は、収入では入金先、支出では支払い元、振替では出金元です。
- **振替先**は振替の入金先で、振替では必須です。口座と振替先は別の口座にしてください。
- 名前が一致する口座がないと、**新しい口座が「現金」の種類で作られます**。カードや銀行の場合は、取り込んだあとに「設定」→「口座」で種類を直してください。

### メモ・店舗名

自由に書けます（空でもかまいません）。カンマ・改行を含む場合は、値を `"` で囲みます（例: `"ランチ, 2人分"`）。表計算ソフトで保存すれば自動で囲まれます。

## ファイルの保存形式

| 項目 | おすすめ | 補足 |
| --- | --- | --- |
| 区切り | カンマ（,） | タブ区切りは、この取り込みでは読み込めません。 |
| 文字コード | UTF-8 | Excel で保存した Shift_JIS の CSV も読み込めます。 |
| 拡張子 | .csv | Excel の .xlsx はこの取り込みでは選べません。CSV で保存し直してください。 |

### 表計算ソフトでの保存のしかた

- **Excel**: 「ファイル」→「名前を付けて保存」→ ファイルの種類「CSV UTF-8 (コンマ区切り)」
- **Numbers**（iPhone・Mac）: 「書き出す」→「CSV」（テキストエンコーディングは UTF-8）
- **Google スプレッドシート**: 「ファイル」→「ダウンロード」→「カンマ区切り形式（.csv）」

保存したファイルを「ファイル」アプリ（iCloud Drive など）に置くと、アプリの「ファイルを選ぶ」から選べます。

## 重複の扱い

すでにアプリにある記録と、**日時（分まで）・種別・カテゴリ（振替は口座の組み合わせ）・金額**がすべて同じ行は、「重複のためスキップ」になり取り込まれません。同じファイルを2回取り込んでも、二重にはなりません。

> **ご注意**
> - 同じファイルの中に同じ内容の行が2行ある場合は、両方とも取り込まれます（同じ日に同じ店で同じ金額を2回使った場合など）。
> - 日時やカテゴリを少しでも変えて取り込み直すと、別の記録として追加されます。やり直す場合は、取り込む前のバックアップからリストアしてから取り込み直してください。

## 取り込み前の確認画面とエラーの直し方

「ファイルを選ぶ」でファイルを選ぶと、取り込む前に件数や新しく作られるもの、「読めなかった行」が表示されます。読めなかった行は「◯行目: 理由」で表示されます（見出しが1行目）。
読めなかった行は取り込まれず、それ以外の行だけが取り込まれます。全部取り込みたい場合は、ファイルを直してから選び直してください。

| 表示される理由 | よくある原因と直し方 |
| --- | --- |
| 日時が読めません | 年がない、和暦、「年月日」表記、日と月の順番が逆など。`2026/10/25 14:30` の形にします。 |
| 種別は「収入」「支出」「振替」のどれかにしてください | 「入金」「出金」「給与」などが入っている。3つのどれかに置き換えます。 |
| 振替には口座と振替先が必要です | 振替の行で、口座か振替先が空。両方入れます。 |
| 口座と振替先が同じです | 振替で同じ口座を指定している。別の口座にします。 |
| カテゴリが空です | 収入・支出の行でカテゴリが空。カテゴリを入れます。 |
| 金額が読めません | マイナス・0・空欄・文字が入っているなど。プラスの数字にします。 |

### 1行目が「読めなかった行」になるとき

見出しに「日時」と「金額」（英語なら「Date」と「Amount」）の両方がないと、見出しとして扱われず、1行目もデータとして読まれます（このとき、列は 日時・種別・カテゴリ・サブカテゴリ・金額・メモ・店舗名・口座・振替先 の順番とみなされます）。
見出しの名前は**完全に一致**させてください。「日付」「利用日」「金額(円)」などは見出しとして認識されません。

### 新しいカテゴリ・口座が思ったより多いとき

確認画面の「新しく作るカテゴリ」「新しく作る口座」に、意図しない名前が並んでいたら、名前の書き間違いや表記ゆれです。取り込む前にファイルの名前をアプリに合わせるか、取り込んだあとで記録を修正し、不要なカテゴリ・口座を削除してください。

## ほかの家計簿アプリから移行するとき

1. 移行元のアプリから、記録を CSV（または Excel）で書き出します。
2. 表計算ソフトで開き、列を次のように対応させます。

| 移行元によくある列 | myKakeibo の列 | 直しかた |
| --- | --- | --- |
| 日付、利用日 | 日時 | 見出しを「日時」に。年・月・日の順の形にする |
| 収支区分、入出金 | 種別 | 値を「収入」「支出」「振替」に置き換える |
| 大項目、費目 | カテゴリ | 見出しを「カテゴリ」に |
| 中項目、小項目、内訳 | サブカテゴリ | 見出しを「サブカテゴリ」に |
| 金額（支出はマイナス） | 金額 | マイナスを外し、種別で向きを表す |
| 収入金額・支出金額の2列 | 金額 | 1列にまとめ、空でないほうの列から種別を決める |
| 財布、口座、支払方法 | 口座 | 見出しを「口座」に。名前をアプリの口座に合わせる |
| 内容、備考 | メモ | 見出しを「メモ」に |
| お店、支払先 | 店舗名 | 見出しを「店舗名」に |

3. 移行元で「振替」がない場合（ATM の引き出しなどが支出になっている場合）は、その行の種別を「振替」に、口座と振替先を入れて、カテゴリを空にします。
4. CSV UTF-8 で保存し、まず数十行だけで試し取り込みをして、確認画面で問題がないことを確かめてから、全体を取り込みます。

> **ヒント**
> 先にアプリの「設定」→「カテゴリ」「口座」を移行元に合わせて整えておくと、取り込み後の修正が少なくなります。

## 銀行・カードの明細ファイル（D 表のファイル）のコツ

「記録」タブの読み取り →「D 表のファイル」は、銀行やカード会社からダウンロードした明細を、**形を整えずにそのまま**読み込む方法です。列は見出しの名前から自動で判断します。

| 読み取る内容 | 認識される見出しの例 |
| --- | --- |
| 日付 | 日付、利用日、取引日、年月日、日時、計上日、Date |
| 内容 | 内容、摘要、利用店、店名、ご利用先、取引内容、明細、加盟店、名称 |
| 出金 | 出金、引出、支払金額、お支払、Debit、Withdrawal |
| 入金 | 入金、預入、預け入れ、Credit、Deposit |
| 金額（1列のとき） | 金額、利用額、Amount |

- 「残高」「手数料」「支払回数」の列は読みません。
- 金額が1列だけのときは、マイナスの行があれば「マイナス = 支出・プラス = 収入」、マイナスがなければすべて支出として読みます。`(1,000)`、`△1,000`、`▲1,000` もマイナスとして読みます。
- 日付は `2026/9/7`、`2026年9月7日`、`26/9/7`、`9月7日`、`9/7` などに対応しています。年がない日付は、今日より先にならないように今年か去年として読みます。
- 日付が読めなかった行は「日付?」と表示され、チェックが外れます。押して日付を選んでください。
- Excel（.xlsx）の場合は、いちばん多く明細が読み取れたシートを使います。
- 日付と金額の列が見つからないときは「日付と金額の列が見つかりませんでした」と表示されます。見出しの行を上のような名前に変えてから選び直してください。

取り込みの手順は [レシート・明細を読み取る](scan) をご覧ください。
