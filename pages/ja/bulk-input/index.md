# 一括入力ページと自動登録
<!-- position: 4 -->
<!-- description: 家賃・光熱費・積立など毎月の項目をまとめて入力する一括入力ページと、毎月の自動登録の使いかたを説明します。 -->

**一括入力ページ**は、給与・家賃・光熱費・積立など、毎月入力する項目をまとめたページです。金額を入れてボタンを1回押すだけで、まとめて記録できます。決まった日に自動で登録することもできます。

はじめから「住まい・光熱費」「通信・サブスク」「ローン・保険・社会保険」の3ページが用意されています。

## 一括入力ページの一覧を開く

次のどちらかで開きます。

- 「記録」タブ右上の一括入力ボタン（チェックリストのアイコン）
- 「設定」→「一括入力ページ」

ページをタップすると入力画面が開きます。右上の鉛筆で編集モードにすると、タップで項目の編集、≡ をドラッグして並び替え、⊖ で削除ができます。

## ページを作る

1. 一括入力ページの一覧で、右下の「+」をタップします。
2. ページ名（例: 毎月の固定費）を入力して「保存」をタップします。
3. 項目の編集画面が開くので、右下の「+」から項目を追加します。

ページ名は、項目の編集画面の右上のボタンから変更できます。ページを削除しても、記録済みの収支データは残ります。

## 項目を追加・編集する

「項目を追加」画面で、次の内容を設定します。

| 設定 | 内容 |
| --- | --- |
| 収入／支出／振替 | 項目の種類を選びます。 |
| カテゴリ | 収入・支出の場合に選びます（サブカテゴリまで選ぶと、毎月の「入力済み」の判定に使われます）。 |
| 名前・出金元・入金先 | 振替の場合に設定します。名前が空なら「出金元 → 入金先」と表示されます。 |
| 初期値 | 入力画面に最初から入る金額です。空欄でもかまいません。サブカテゴリに「毎月固定」の金額があるときは、空欄ならその金額が使われます。 |
| メモ | 記録に付けるメモです。 |
| 毎月自動で登録する | オンにすると、この項目が自動登録の対象になります（初期値の金額が必要です）。 |

項目はタップで編集できます。右上の鉛筆で編集モードにすると、並び替え・削除ができます。

## まとめて入力する

一括入力ページをタップするか、「記録」タブの各タブで「一括」を選んでページを選ぶと、入力欄が表示されます。

![一括入力](https://raw.githubusercontent.com/shibatype1999/myKakeibo-manual/main/images/ja/bulk-input.png)

1. いちばん上の**日時**を確認します。タップすると変更できます。その下に「◯項目中 ◯項目が◯月に入力済み」と表示されます。
2. **支払い元・入金先**の口座を選びます（振替だけのページでは表示されません）。
3. 各項目の金額を入力します。保存しない項目はチェックを外します。振替の項目は、出金元・入金先を押すとその回だけ口座を変えられます。
4. 「チェックした項目をまとめて保存」をタップします。

> **ヒント**
> - その月にすでに入力した項目には「入力済み」と表示され、最初からチェックが外れています。二重入力を防ぐためです。
> - 入力済みの項目をチェックして保存しようとすると、「入力済みの項目があります」と確認が出ます。
> - 「記録」タブの「一括」では、そのタブの種類（収入・支出・振替）の項目があるページだけが表示されます。

## 毎月自動で登録する

家賃や積立など、毎月同じ金額のものは、決まった日に自動で登録できます。

1. 項目の編集画面で、自動で登録したい項目を開き、初期値を入れて「毎月自動で登録する」をオンにします。その項目には「自動」と表示されます。
2. 項目の編集画面の上にある「毎月自動で登録する」（ページの設定）をオンにします。
3. 次の内容を設定します。

| 設定 | 内容 |
| --- | --- |
| 登録する日 | 毎月1日〜28日、または「月末」 |
| 土日のとき | 「そのまま」「前の金曜日」「次の月曜日」 |
| 時刻 | 登録する時刻 |
| 支払い元・入金先 | 記録に使う口座（決めていないときは銀行口座） |

自動登録した記録には、一覧で「自動登録」と表示されます。

> **ご注意**
> - iPhone では、アプリを閉じている間は登録できません。**アプリを開いたとき（またはほかのアプリから戻ったとき）**に、登録日時を過ぎた分をまとめて登録し、「◯◯を◯件自動で登録しました」と表示します。
> - しばらくアプリを開かなかった場合は、最大12か月分さかのぼって登録します。
> - 自動登録をオンにした月から登録します。それより前の月の分は登録しません。
> - その月にすでに入力済みの項目は、自動では登録しません。

## サブカテゴリの「毎月固定」との違い

サブカテゴリの設定で「毎月固定」をオンにすると、毎月はじめに金額が決まっていない「予定」の記録が作られます（一覧に黄色で表示されます）。一括入力ページから同じサブカテゴリを保存すると、新しい記録を作らずにその予定を確定します。詳しくは [カテゴリ・サブカテゴリ](categories) をご覧ください。
